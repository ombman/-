## STEP 2 　バックエンドコードを設置　（3分）

2. 左サイドバーの **`</>` （開発者モード／Velo）** を開く

4. ファイル名を **`properties.web.js`** にする（`.web.js` まで正確に）

## STEP 3 　ページを2枚つくる　（15分）

### 3-A　ユーザー画面（トップページ）

1. ページメニュー → トップページを選択
2. 左の「＋」→ **埋め込み** → **HTMLコード**（"Embed HTML"）を配置
3. 配置した枠をクリック →「コードを入力」→ **コード** モードを選択
4. **`wix-embed/paste-into-wix.html` の中身を全文貼り付け** → 適用
5. 枠のサイズを　幅：最大　高さ：**2000px** 程度に広げる
6. 枠を選択した状態で、右上のプロパティで **ID が `html1`** であることを確認
   　（違う場合は、次で貼るコードの `#html1` をその ID に書き換える）
7. 画面下の **ページコード** 欄に `velo/pages/public-page.js` の内容を貼り付け

### 3-B　管理画面

1. ページメニュー → **ページを追加**（空白ページ）
2. ページ名「管理画面」、**URLスラッグを `admin`** にする
3. **ページ設定 → 権限 → パスワードで保護** を設定（Wix側の1段目の鍵）
4. 3-A と同じ手順で HTMLコードを配置し、**同じく全文貼り付け**
5. ページコード欄に `velo/pages/admin-page.js` の内容を貼り付け

### ⚠ 貼り付けが文字数上限で弾かれた場合

`paste-into-wix.html` は 33,625 文字です。もし Wix に拒否されたら、URL方式に切り替えます。

1. GitHub → このリポジトリ → **Settings → Pages** → Source を **GitHub Actions** に変更
2. 数分後 `https://ombman.github.io/-/index.html` が有効になる
3. HTMLコードの枠を **「ウェブサイトのアドレス」モード**に切り替え、
   　ユーザー画面には `https://ombman.github.io/-/index.html?mode=public`
   　管理画面には　　 `https://ombman.github.io/-/index.html?mode=admin`
   　を入力（ページコードはそのままで動きます）

## 補足：セキュリティについて

- 貼り付けるHTMLの中に `FALLBACK_PASSWORD: 'admin1234'` という記述がありますが、
  これは **Wix CMS に接続できていないときだけ**使われる予備の値です。
  接続後はサーバ側（シークレットマネージャー）で検証されるため使われません。
- ただしHTMLは訪問者から見えるため、**この文字列は別の値に変更しておくことを推奨**します
  （`wix-embed/index.html` を編集 →`node test/build-paste.mjs` で再生成）。
- 物件データの書き込みは Velo バックエンドが担当し、トークン検証を通らない限り
  CMS には保存されません。ブラウザ側から直接CMSを書き換えることはできない構成です。
