# Wix 不動産ランディングページ 設置手順

所要時間の目安：**30〜45分**（Wixの操作に慣れている場合は20分程度）

---

## ⚠ 前提：サイトの種類に注意（最重要）

本構成は Wix の **Velo（サイトコード）** を使います。Velo が使えるのは以下だけです。

| サイトの種類 | Velo（サイトコード） | 本構成の可否 |
|---|---|---|
| Wix エディタ（クラシック） | ○ 使える | **可** |
| Wix Studio | ○ 使える | **可** |
| **Wix Harmony（AI生成エディタ）** | **× 使えない** | **不可**（HTML/JS/CSSの埋め込みのみ対応） |

出典: [Types of Wix Sites](https://dev.wix.com/docs/overview/platform-overview/types-of-wix-sites)
— "Wix Harmony is Wix's AI-powered editor. Harmony sites don't support site code."

Harmony サイトでもウィジェットの画面・読み取り・削除・LINEボタンは動作しますが、
**Wix CMS と接続できないため、管理者が登録した物件が訪問者に表示されません**
（そのブラウザにのみ保存される「標準モード」になります）。
必ず **Wix エディタ（クラシック）または Wix Studio** のサイトをご用意ください。

---

## 0. 全体の構成（なぜこの作りなのか）

| 要件 | 実現方法 | 理由 |
|---|---|---|
| ① ユーザー画面／管理画面の分離 | Wix のページを2枚（`/` と `/admin`）作り、それぞれに同じウィジェットを別モードで埋め込む | Wix のページ単位で「パスワード保護」をかけられるため |
| ② ドラッグ＆ドロップ枠 | `wix-embed/index.html`（HTML iframe に埋め込み） | Wix の標準要素にドロップ解析機能が無く、JavaScript が必須のため |
| ③ 資料の自動読み取り | pdf.js でPDFからテキスト抽出 → 正規表現で項目抽出 | ブラウザ内で完結、資料を外部サーバに送らない |
| ④ 情報元の削除 | 正規表現によるマスキング（HTML側＋Velo側の二重チェック） | 電話番号・会社名・担当者名などの誤掲載を防ぐ |
| ⑤ Meiryo UI | CSS の `font-family` 先頭に指定 | — |
| ⑥⑦ LINE ボタン | 全ボタンの `href` を `https://lin.ee/ucovrzE` に統一 | — |
| 公開画面と管理画面のデータ共有 | Wix CMS（`Properties` コレクション）＋ Velo | ブラウザ保存だけでは管理者以外に見えないため |

> **重要**：Wix の標準機能（ノーコード）だけでは ②③④ は実現できません。本手順は
> Wix の **Velo（開発者モード）** を有効にして行います。

---

## 1. ウィジェットを公開URLに置く

`wix-embed/index.html` をインターネット上のURLで配信します。

### 方法A：GitHub Pages（無料・推奨）
1. このリポジトリを GitHub に push
2. GitHub → **Settings → Pages** → Source を `GitHub Actions` に設定
3. 同梱の `.github/workflows/pages.yml` が `wix-embed/` を公開します
4. 公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/index.html`

### 方法B：Wix の HTML 埋め込みに直接貼り付け（推奨・URL不要）
Wix エディタの **埋め込み → HTMLコード** に、圧縮版 `wix-embed/paste-into-wix.html` の中身を
そのまま貼り付けます。外部の配信URLもドメイン設定も不要で、Wixサイト内で完結します。

- 圧縮版は 33,625 文字（元 44,192 文字）です。`node test/build-paste.mjs` で再生成できます。
- 編集は必ず `wix-embed/index.html` 側で行い、再生成してから貼り直してください。
- 貼り付け方式では URL の `?mode=admin` が使えませんが、Velo ページコードが送る `setMode`
  メッセージで画面が切り替わるため問題ありません（テスト済み）。
- 独自ドメインが既に Wix に接続されている場合（例：`ombman.com`）、Wix はファイルサーバでは
  ないため、そのドメイン配下に HTML ファイルを置くことはできません。方法Bを使ってください。

## 2. Wix 側の準備

### 2-1. 開発者モード（Velo）を ON
エディタ上部 → **開発者モード → コーディングをオンにする**

### 2-2. CMS コレクション `Properties` を作成
**CMS → コレクションを作成** → 名前を `Properties` にして、以下のフィールドを追加します。

| フィールド名（Field ID） | 種類 | 用途 |
|---|---|---|
| `title` | テキスト | 物件名 |
| `propertyType` | テキスト | `house` または `mansion` |
| `priceMan` | 数値 | 価格（万円） |
| `walkMin` | 数値 | 駅からの徒歩分数 |
| `station` | テキスト | 最寄駅 |
| `ageYears` | 数値 | 築年数 |
| `builtLabel` | テキスト | 建築年月の表示用 |
| `floorArea` | 数値 | 延床面積（戸建） |
| `ownArea` | 数値 | 専有（占有）面積（区分所有） |
| `ownShare` | テキスト | 持分（区分所有） |
| `sourceFile` | テキスト | 元資料のファイル名 |

**権限設定**（コレクション設定 → 権限）:
- 読み取り：**全員**
- 追加・更新・削除：**管理者**
（書き込みは Velo バックエンドが `elevate()` で行うため、これで問題ありません）

### 2-3. シークレットを登録
Wix ダッシュボード → **設定 → シークレットマネージャー** で2つ登録します。

| キー | 値 |
|---|---|
| `adminPassword` | 管理画面のログインパスワード（自分で決める） |
| `adminTokenSalt` | 十分に長いランダム文字列（例：`openssl rand -hex 32` の出力） |

### 2-4. バックエンドコードを追加
エディタのコードサイドバー → **バックエンド** に新規ファイル `properties.web.js` を作り、
`velo/backend/properties.web.js` の内容を貼り付けます。

---

## 3. ページを2枚作る

### 3-1. ユーザー画面（公開）
1. ページを追加（例：トップページをそのまま使用）
2. **埋め込み → ウェブサイトを埋め込む（HTML iframe）** を配置
3. 「ウェブサイトのアドレス」に `https://<公開URL>/index.html?mode=public` を入力
4. 要素の ID が `html1` であることを確認（違う場合はページコードの `#html1` を合わせる）
5. 高さは大きめ（例：2000px）に設定するか、ページに合わせて調整
6. そのページのコードパネルに `velo/pages/public-page.js` を貼り付け

### 3-2. 管理画面
1. ページを追加し、URL を `/admin` にする
2. **ページ設定 → 権限 → パスワードで保護** を設定（Wix 側の1段目の鍵）
3. 同じく HTML iframe を配置し、URL は `https://<公開URL>/index.html?mode=admin`
4. そのページのコードパネルに `velo/pages/admin-page.js` を貼り付け

### 3-3. 公開
エディタ右上の **公開** を押して反映します。

---

## 4. 使い方（管理者）

1. `https://<サイト>/admin` を開き、`adminPassword` でログイン
2. 「④ 追加で削除するワード」に自社名・担当者名などを1行ずつ入れて保存
   （自動検出に加え、必ず削除されます）
3. 物件資料（PDF）を枠にドラッグ＆ドロップ
4. 読み取り結果を確認（**読み取れなかった項目は赤枠になるので手入力**）
5. 「ユーザー画面に掲載」を押すと公開されます

### 読み取り対象（※1の仕様）
| 種別 | 自動で読み取る項目 |
|---|---|
| 戸建 | 価格 ／ 駅からの徒歩分数 ／ 築年数 ／ 延床面積 |
| マンション・区分所有 | 価格 ／ 駅からの徒歩分数 ／ 築年数 ／ 専有（占有）面積 ／ 持分 |

種別は資料内の語（「専有面積」「敷地権」「管理費」など ⇔「延床面積」「土地面積」「建ぺい率」など）から
自動判定し、確認画面で手動変更できます。

### 自動削除される情報（④）
電話番号・FAX・フリーダイヤル ／ メールアドレス ／ URL ／ 法人格を含む会社名（株式会社・有限会社など）
／ 「〇〇不動産」「〇〇住宅販売」等の社名 ／ 宅建業免許番号 ／ 担当者・窓口・取扱店の記載 ／ 本社・支店の所在地
／ 管理者が指定した追加ワード

## 5. 制限事項（事前にご確認ください）

- **画像のみのPDF（スキャン資料・FAX原稿）は読み取れません。** テキストが埋め込まれたPDFが必要です。
  文字認識（OCR）は日本語の物件図面では精度が実用水準に届かないため、あえて実装していません。
  該当ファイルはエラー表示になるので、手入力してください。
- **自動読み取りは100%ではありません。** 資料の書式は会社ごとにバラバラなため、
  必ず確認画面で目視チェックしてから掲載する運用にしてください（そのために確認ステップを挟んでいます）。
- **④の削除も同様に完全ではありません。** 特に法人格の付かない屋号（例：「〇〇商会」）は
  自動検出できない場合があります。「追加で削除するワード」への登録を必ず行ってください。
  掲載前に「削除後のテキストを確認する」で本文を確認できます。
- Wix CMS を接続していない場合、ウィジェットは**標準モード**（そのブラウザにのみ保存）で動作します。
  管理画面の右上に警告バッジが出ます。本番では必ず手順2〜3を実施してください。
