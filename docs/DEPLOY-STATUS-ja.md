## 要操作（Wix の画面でのみ可能）

### 1. シークレットを2つ登録
ダッシュボード → 設定 → シークレットマネージャー

| キー | 値 |
|---|---|
| `adminPassword` | 管理画面のログインパスワード（ご自身で決める） |
| `adminTokenSalt` | `e17df47da13f4fefa6b4c9f50f5503494e8700d55ca5e6aa0e9257c80d1d4190` |

※ `adminTokenSalt` は本リポジトリ用に生成したランダム値です。気になる場合は
`openssl rand -hex 32` で作り直した値に差し替えてください。

### 2. バックエンドコードを追加
エディタ → 開発者モード → バックエンド → 新規ファイル `properties.web.js`
→ `velo/backend/properties.web.js` の内容を貼り付け

### 3. ページを2枚作る

| ページ | URLスラッグ | 埋め込む内容 | ページコード |
|---|---|---|---|
| ユーザー画面 | `/`（トップ） | HTMLコード：`wix-embed/paste-into-wix.html` の全文 | `velo/pages/public-page.js` |
| 管理画面 | `/admin` | 同上 | `velo/pages/admin-page.js` |

- HTML要素のIDが `html1` であることを確認（違う場合はページコードの `#html1` を合わせる）
- 高さは 2000px 程度に設定
- 管理画面ページは **ページ設定 → 権限 → パスワードで保護** を設定

### 4. Premium 契約とサブドメイン割り当て
`fudosan.ombman.com` を本サイトに割り当てる。
※ サブドメイン利用に必要なプラン条件・料金は Wix の料金ページでご確認ください。

### 5. 公開
エディタ右上の「公開」

## 動作確認の手順

1. `/admin` を開き、`adminPassword` でログイン
2. 管理画面の右上バッジが **「Wix CMS 接続中（全訪問者に公開）」** になっていることを確認
   （「標準モード」と出る場合は、バックエンドコードかページコードが未設置）
3. 物件PDFをドラッグ＆ドロップ → 読み取り結果を確認 → 「ユーザー画面に掲載」
4. 別のブラウザ（またはシークレットウィンドウ）でトップページを開き、物件が表示されることを確認
