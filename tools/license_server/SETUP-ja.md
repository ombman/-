# ライセンス認証サーバーの作り方（配布元が1回だけ行う・約10分・無料）

Googleスプレッドシート＋Google Apps Script（Googleの無料の自動処理）で作ります。

## 1. スプレッドシートを作る
1. https://sheets.new を開く（Googleアカウントでログイン）
2. 左上の名前を「REINSアプリ ライセンス管理」などに変える

## 2. プログラムを貼る
1. 上のメニュー「拡張機能」→「Apps Script」
2. 最初から入っている文字を全部消し、このフォルダの `Code.gs` の中身を全部貼る
3. 💾（保存）を押す

## 3. ウェブアプリとして公開する
1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車 ⚙ →「ウェブアプリ」を選ぶ
3. 次のとおり設定して「デプロイ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「アクセスを承認」→ 自分のGoogleアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
5. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

## 4. アプリにURLを入れる
`config/license_server.json` の `server_url` に、手順3のURLを貼って保存する。
（GitHubに反映すると、利用者の「update」でも自動で配られます）

## 5. キーを発行する
1. スプレッドシートを開き直す → 上に「ライセンス管理」メニューが出る
2. 「シートを準備（初回のみ）」を押す
3. 「新しいキーを発行」→ 利用者名を入れる → 表示されたキー（例 `RA-7K3P-9QXM-2D8F`）を利用者に伝える

## 運用
| やりたいこと | 操作 |
|---|---|
| 利用を止める | その行の C列（status）を `revoked` にする |
| 有効期限を付ける | D列（expires）に日付を入れる（例 2027/3/31）。その日の終わりまで有効 |
| REINS IDの変更に対応する | E列（idHash）と F列（boundAt）を消す → 次に使ったREINS IDに紐づき直す |
| 使われているか見る | G列（lastCheck）に最後に起動した日時が入る |

- シートに入るのはREINS IDを暗号化した値だけで、REINS IDそのものは保存されません。
- ネットにつながらない時は、最後に認証できてから7日間だけ起動できます（停止したキーは除く）。
