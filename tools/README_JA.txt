REINS自動検索アプリ　はじめにお読みください
==================================================

【できること】
REINSにログインし、指定した条件（物件種別・沿線・価格）で売買物件を検索して、
図面を一括で C:\reins\downloads に保存します。
※ Windows 10 / 11 専用です。REINSのログインID・パスワードが必要です。

【インストール（初回だけ・約5〜10分）】
1. ダウンロードしたZIPを右クリック →「すべて展開」→「展開」
2. 展開されたフォルダの中の「install」（install.bat）をダブルクリック
   ・「WindowsによってPCが保護されました」と出たら
     「詳細情報」→「実行」を押してください。
   ・Pythonが入っていないパソコンでは、自動でPythonを入れます。
3. 黒い画面に「Installation finished.」と出たら完了です。
   デスクトップに「REINS自動検索」アイコンができます。

【使い方】
1. デスクトップの「REINS自動検索」をダブルクリック
2. 初回だけ：ライセンスキー（配布元から受け取ったもの）と、
   REINSのログインURL・ID・パスワードを入力して保存
   ※ライセンスキーは、最初に使ったREINS ID 1つにだけ使えます
   （パスワードはWindowsの資格情報マネージャーに暗号化して保存されます）
3. 検索条件の画面で条件を確認し「この条件で検索開始」
4. 終わると C:\reins\downloads に図面のPDFが入ります

【最新版への更新】
C:\reins の「update」（update.bat）をダブルクリック

【うまく動かないとき】
・C:\reins\logs に記録と画面写真が残ります
・インストールで止まった場合は C:\reins\setup_log.txt を確認してください
