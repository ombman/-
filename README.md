# REINS自動検索アプリ

Windows 11 上で Google Chrome を自動操作し、REINS（不動産流通標準情報システム）に
ログイン → 売買物件検索 → 図面の一括取得まで自動で行うアプリです。

---

## まず結論（何をすればいいか）

1. **Python（プログラミング言語）をインストール**する（初回のみ）
2. このフォルダの **`setup.bat` をダブルクリック**する（初回のみ・必要な部品を自動導入）
3. **`run.bat` をダブルクリック**する → 初回はURLとログイン情報の入力画面が開く
4. デスクトップに **`run.bat` のショートカット（アイコン）を作成**する → 以後はダブルクリックで起動

これだけで動きます。詳しい手順は下の「導入手順」を読んでください。

### アプリを最新版に更新するとき

一度セットアップ済みのフォルダで **`update.bat` をダブルクリック**するだけで、
GitHubから最新の `src`（プログラム）と `config`（検索手順）を取得して更新します。
`.venv`（導入済みの部品）と `settings.json`（あなたのURL・ログイン設定）は
**そのまま保持**されるので、`setup.bat` をやり直す必要はありません。

---

## このアプリの特徴（設計方針）

REINSは画面の作りやボタンの位置が変わることがあります。そのため
「画面の座標を固定でクリックする」方式は壊れやすく採用していません。

代わりに、次の順で動きます（**要素優先方式**）。

1. 画面を確認する
2. 対象のボタン・入力欄・選択欄を **HTMLの要素（ラベル・ボタン名・input・select 等）で特定**する
3. 操作する（クリック／入力／選択）
4. 操作結果を確認する（例:「売マンション」と表示されたか）
5. 正常に進んだことを確認してから次へ進む

- 特定条件は**複数の候補を上から順に試す**ため、多少画面が変わっても追従できます。
- HTMLで特定できないときの**補助手段としてだけ座標クリック**を使います。
- 検索手順は **`config/search_recipe.json`（設定ファイル）に外出し**しており、
  プログラムを書き換えずに手順を調整できます。

### セキュリティ（ID・パスワードの扱い）

- ID・パスワードは**ソースコードや設定ファイルには保存しません**。
- **Windowsの資格情報マネージャー（OS標準の暗号化された安全な保管庫）**に保存します
  （`keyring` というライブラリを使用）。
- 入力画面でも**パスワードは伏せ字（●）表示**にし、画面に表示しません。
- ログイン失敗時は先へ進まず、
  「**REINSへのログインに失敗しました。ログイン情報を確認してください。**」
  と表示して停止します。

## 導入手順（初心者向け・順番どおりに）

### 手順1: Python をインストール（初回のみ）

1. https://www.python.org/downloads/windows/ を開く
2. 「Download Python 3.11.x」など **3.11 以上**をダウンロードして実行
3. インストール画面の下にある **「Add python.exe to PATH」に必ずチェック**を入れて「Install Now」
   - ここのチェックを忘れると `setup.bat` が Python を見つけられません。

### 手順2: このアプリのフォルダを用意

- このプロジェクト一式（`setup.bat` や `run.bat` があるフォルダ）を、
  例えば `C:\reins-auto-search\` のように分かりやすい場所へ置きます。

### 手順3: セットアップ（初回のみ）

- フォルダ内の **`setup.bat` をダブルクリック**します。
- 黒い画面（コマンドプロンプト）で自動的に必要な部品を導入します（数分かかります）。
- 「セットアップが完了しました」と出れば成功です。

> 何をしているか: このアプリ専用の実行環境（仮想環境 `.venv`）を作り、
> `playwright`（ブラウザ自動操作）と `keyring`（安全なパスワード保管）を導入しています。

### 手順4: 起動と初回設定

- **`run.bat` をダブルクリック**します。
- 初回は**設定画面**が開きます。ここで入力します:
  - **REINS ログインページのURL**（お使いのREINSのログイン画面URLを貼り付け）
  - **ログインID**
  - **パスワード**（●で伏せ字表示。保存はWindowsの安全な保管庫へ）
- 「保存して閉じる」を押すと、Chromeが起動して自動処理が始まります。

> URLは私（開発側）が勝手に決め打ちしていません。必ずご自身のREINSのURLを入力してください。

### 手順5: デスクトップにアイコン（ショートカット）を作る

1. `run.bat` を**右クリック** →「送る」→「デスクトップ（ショートカットを作成）」
2. デスクトップにできたアイコンを右クリック →「名前の変更」で
   「REINS自動検索」など分かりやすい名前に変更
3. （任意）アイコン絵柄を変えたい場合: 右クリック →「プロパティ」→「アイコンの変更」

以後は、この**アイコンをダブルクリックするだけ**で起動できます。

- 設定を変えたい: **`settings.bat` をダブルクリック**（URL・ログイン情報の変更／削除）

## 検索条件を変えたい・画面変更に対応したいとき

検索手順は **`config/search_recipe.json`** に書かれています。
メモ帳などで開き、各ステップの `targets`（特定条件）や `value`（入力値）を編集します。

例: 「駅から徒歩」の分数を 10 → 5 に変える

```json
{
  "id": "ensen1_walk_minutes",
  "action": "fill",
  "value": "5",
  "targets": [ { "by": "label", "value": "駅から徒歩" } ]
}
```

### ボタンや入力欄の「正しい特定条件」を調べたいとき

実際のREINS画面で要素名を調べる補助ツールがあります。

```
python tools\inspect.py
```

Chromeと一緒に「Inspector」が開きます。「Explore」を押して画面の要素をクリックすると、
その要素の特定方法（例: `get_by_role("button", name="ログイン")`）が表示されます。
それを `search_recipe.json` の `targets` に反映すると確実です。

## うまく動かないとき（トラブル対処）

- **`[WinError 206] ファイル名または拡張子が長すぎます` / インストール失敗**
  → フォルダの場所が深すぎてWindowsのパス長制限(260文字)を超えています。
  次の2点で解決します：
  1. ZIPは**必ず「すべて展開」で解凍**してから使う（ダウンロードフォルダやTemp内・
     ZIPを開いただけの場所で実行しない）。
  2. **短い場所に置く**。例：`C:\reins` フォルダを作り、その直下に `setup.bat` が
     来るように中身をコピーしてから `setup.bat` を実行する（`C:\reins\setup.bat`）。

- **どこで止まったか**は、まず `logs` フォルダのログと、`logs\shots` フォルダの
  スクリーンショット（各ステップの画面写真）を見てください。原因の特定が早くなります。
- 「対象を特定できませんでした」と出た場合 → そのステップの `targets` を
  `tools\inspect.py` で調べた内容に更新してください。
- ゆっくり動かして確認したい場合 → `config/settings.json` の
  `"step_by_step_pause": true` にすると、各ステップごとに一時停止します。
- Chromeが見つからない場合 → Google Chromeをインストールするか、
  `config/settings.json` の `"browser_channel"` を空文字 `""` にすると予備ブラウザで動きます。

## 図面のダウンロード先

「図面の一括取得」で取得したファイルは、プロジェクト直下の **`downloads` フォルダ**に
保存されます（自動作成）。保存先を変えたい場合は `src/browser.py` の `DOWNLOAD_DIR` を変更してください。

## フォルダ構成

```
reins-auto-search/
├── README.md              ← この説明書
├── requirements.txt       ← 必要ライブラリ一覧
├── setup.bat              ← 初回セットアップ（ダブルクリック）
├── run.bat                ← アプリ起動（ショートカット対象）
├── settings.bat           ← 設定画面を開く
├── config/
│   ├── settings.example.json  ← 設定の雛形
│   ├── settings.json          ← あなたの設定（自動生成・URL等）
│   └── search_recipe.json     ← 検索手順（編集可能）
├── src/                   ← プログラム本体
│   ├── main.py            ← 入口
│   ├── config.py          ← 設定の読み書き
│   ├── credentials.py     ← ID/パスワードを安全に保存
│   ├── settings_gui.py    ← 設定画面
│   ├── browser.py         ← Chrome起動
│   ├── locator.py         ← 要素の特定（複数戦略）
│   ├── reins_login.py     ← ログイン処理
│   ├── reins_search.py    ← 検索手順の実行エンジン
│   └── app_logger.py      ← ログ・スクリーンショット
├── tools/
│   └── inspect.py         ← 要素の特定条件を調べる補助ツール
└── logs/                  ← ログと画面写真（自動生成）
```
