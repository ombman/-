# 不動産物件紹介 ランディングページ（Wix 用）

Wix サイトに組み込む、物件紹介ランディングページ一式です。
管理者が**物件資料をドラッグ＆ドロップするだけ**で、必要項目を自動で読み取り、
資料に載っている情報元（電話番号・会社名・担当者名など）を自動削除して掲載します。

## 対応している要件

| # | 要件 | 実装 |
|---|---|---|
| ① | ユーザー画面と管理画面を分ける | 2ページ構成（`?mode=public` / `?mode=admin`）＋管理画面はパスワード保護 |
| ② | 管理画面にドラッグ＆ドロップ枠 | `wix-embed/index.html` のドロップゾーン（複数ファイル同時可） |
| ③ | 資料の情報を自動読み取り | pdf.js でテキスト抽出 → 種別判定 → 項目抽出（※1準拠） |
| ④ | 情報元の削除 | 正規表現マスキング（HTML側）＋保存時のサーバ側チェック（Velo） |
| ⑤ | フォントは Meiryo UI | CSS `font-family` の先頭に指定 |
| ⑥ | LINE 問い合わせボタン | ヘッダー／ヒーロー／各物件カード／画面右下の追従ボタン |
| ⑦ | LINE リンク先 | `https://lin.ee/ucovrzE` |

**※1 種別ごとの読み取り項目**

- 戸建：価格、駅からの徒歩分数、築年数、延床面積
- マンション／区分所有：価格、駅からの徒歩分数、築年数、専有（占有）面積、持分

## ファイル構成

```
wix-embed/index.html          ウィジェット本体（ユーザー画面＋管理画面）
velo/backend/properties.web.js Wix Velo バックエンド（CMS読み書き・認証）
velo/pages/public-page.js      ユーザー画面のページコード
velo/pages/admin-page.js       管理画面のページコード
docs/SETUP-ja.md               Wix への設置手順
test/run.mjs                   Playwright による自動動作確認（69項目）
```

## 設置手順

[docs/SETUP-ja.md](docs/SETUP-ja.md) を参照してください。

## 動作確認

```bash
cd test && npm install && node run.mjs
```

## 制限事項

- 画像のみのPDF（スキャン・FAX原稿）はテキストが抽出できないため読み取れません。手入力で対応します。
- 自動読み取り・自動削除は100%ではありません。掲載前の確認画面で必ず目視チェックしてください。
